Panel Data BPS

Tempat memperbarui data statistik yang tampil di aplikasi Lawang. Masuk dengan token GitHub untuk mulai mengedit.

Bagaimana cara mendapatkan token?
  1. Buka github.com lalu masuk ke akun BPS.
  2. Klik Settings → Developer settings.
  3. Pilih Personal access tokens → Tokens (classic).
  4. Klik Generate new token, beri nama "Update Data BPS".
  5. Centang akses repo, lalu klik Generate.
  6. Salin token dan tempel di kolom di atas.

🔒Token hanya tersimpan di browser ini selama sesi berlangsung dan tidak dikirim ke server mana pun.
